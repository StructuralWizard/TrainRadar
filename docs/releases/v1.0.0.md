# TrainRadar 1.0

Live map of Renfe trains in Spain, coloured by delay. Everything runs in your browser.

- **Live:** https://trainradar.pages.dev (installable on your phone's home screen)
- Trains coloured by delay, with stats, a delayed-arrivals list and a popup per train: route, next stop, delay, GPS age, and spacing to the train ahead and behind
- AV/LD/MD trains follow real track from OpenStreetMap; Cercanías follow Renfe's shapes
- Optional location: nearest stations with their next trains, trains approaching, and "Am I on this train?". Location never leaves your browser
- Renfe's notices with lines and stations, and a link to Adif's network status
- Spanish and English
- Deployed on Cloudflare's free tier: static site on Pages, a tiny pass-through Worker for Renfe's feeds (which send no CORS headers), and reference data rebuilt nightly when Renfe's timetables change
