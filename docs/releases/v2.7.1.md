# 2.7.1: Train details free in the app, updates from inside the app

- The app now shows every train's full details for free, as the web always has: the trains ahead and behind, oncoming trains, the track (line speed, electrification, number of tracks) and the gradient with its height profile.
- Updates from inside the app: when Google Play has a newer version (testers get test releases first), the app offers it and downloads it in the background while you keep using it, then asks to restart. Critical fixes can require the update before going on.
- Más → "Sugerencias y errores" (and About) links to GitHub, where anyone can report a bug or suggest a change.
- TrainRadar Pro is now a yearly subscription: €1.99 a year. If you already have the monthly plan, you keep Pro.
