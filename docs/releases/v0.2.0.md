# Phase A2: reference data builder

`refdata-build` turns Renfe's static GTFS into small, pre-indexed files for the browser.

- Stations file: 1,471 stations nationwide with a spatial grid index for nearest-station queries
- Timetables: AV/LD/MD plus 15 Cercanías núcleos, each loaded on demand
- Trip patterns, a 7-day window, delta-encoded shapes: 288 MB of Cercanías stop times become 2–69 KB per núcleo (gzip)
- Initial download: 128 KB gzipped (stations + AV/LD/MD)
- Cercanías shapes from GTFS (90% of patterns fit); AV/LD/MD uses straight segments for now
- `verify` command and CI workflow that builds, checks and reports sizes on every PR
- Release workflow to create tags and releases from the Actions tab
