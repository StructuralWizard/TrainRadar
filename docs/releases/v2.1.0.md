# 2.1: several commutes

- Android app, TrainRadar Pro: save up to 10 commutes (home → work, work → home, the weekend trip…). They show as tabs in "Trayecto habitual"; choose «Salgo de aquí» and «Voy aquí» in two station popups to add another. The app opens on the one you used last. Your existing commute is kept.
