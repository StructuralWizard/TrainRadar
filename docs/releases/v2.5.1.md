# 2.5.1: Replay fixes

- Moviola: the time slider can be dragged again (it was rebuilt under your finger and stopped moving).
- Moviola: when the chosen time is before the recording began, it starts at the first recorded minute instead of an empty map.
- Server: the replay's hour file is written every minute, so nothing is lost when the server restarts. Its progress (hour, minutes and trains saved) shows in rt/recorder.json.
