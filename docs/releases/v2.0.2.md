# 2.0.2: the Pro screen no longer waits for ever

- Android app: "TrainRadar Pro y ajustes" stayed on "Consultando Google Play…" when one of the app's products (a tip) wasn't set up in Play Console yet. A missing product no longer blocks the others, and if Google Play really fails the screen says so instead of waiting.
