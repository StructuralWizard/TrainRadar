# 2.0.1: the Android app loads its data

- Android app: the map showed no lines or trains. The app's built-in timetables and track were stored compressed, and Android's build tools unpacked and renamed them, so the app couldn't find them. They're now stored unpacked, and the build checks that every file the app needs is there.
