# Phase A4: the map

TrainRadar now has its web app. It runs locally; public deployment is phase A7.

- MapLibre map with OpenFreeMap tiles (free, no API key), coloured train dots: on time / <5 min, 5–14 min, 15+ min, no data
- Stats bar: trains on the map, number delayed, median delay, time since the last update
- Delayed-arrivals list, worst first; tap one to fly to it
- Train popup: service and number, origin → destination, next stop with expected time, delay (Renfe or estimated), GPS fix age, and spacing to the train ahead and behind
- Spanish by default, English on request (remembered on the device)
- Mobile-first layout; Cercanías timetables load per region as you zoom in, track geometry after first paint
- Keeps working with a blank background if the tile server is down
- Offline demo mode (synthetic data + fake feeds) and browser tests in CI on demo and live data
